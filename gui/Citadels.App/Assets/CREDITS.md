# Credits

This is a fan-made version of Citadels for playing at home. It is not affiliated with the
publishers of Citadels, and it uses none of the original card artwork.

## Icons

From [game-icons.net](https://game-icons.net), licensed under
[Creative Commons BY 3.0](https://creativecommons.org/licenses/by/3.0/) (see `ICONS-LICENSE.txt`):

- by **Lorc** (http://lorcblog.blogspot.com): crown, crown-coin, hourglass, eye-shield, laurels,
  scroll-unfurled, magic-palm, magic-swirl, tower-fall, hood, pointy-hat, scales, hammer-nails,
  crossed-swords, crystal-ball
- by **Delapouite** (https://delapouite.com): coins, castle, village, trophy-cup, spell-book, sparkles,
  fleur-de-lys, trowel, card-exchange, robber, abbot-meeple, church, shop, watchtower

The icon paths were converted to plain move/line/curve commands (`Controls/Icons.cs`) and are drawn
in one colour; their shapes are unchanged. The "cards" icon was drawn for this project.

## Fonts

- **Cinzel** by the Cinzel Project Authors, SIL Open Font License 1.1 (`Fonts/OFL-Cinzel.txt`)
- **Inter** by the Inter Project Authors, SIL Open Font License 1.1 (`Fonts/OFL-Inter.txt`)

The variable fonts from the Google Fonts repository were turned into static weights
(Cinzel Regular/Bold, Inter Regular/Medium/SemiBold/Bold) so every platform shows the same weights.
